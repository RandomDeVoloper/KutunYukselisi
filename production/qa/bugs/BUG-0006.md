## Reproduction Steps
**Preconditions**: Oyun tam ekran modunda başlatılmış

1. Oyunu tam ekranda başlat
2. Windowed moda geç (Alt+Enter veya ayarlar)
3. Tekrar tam ekrana geç

**Expected Result**: Çözünürlük tam ekranda native kalmalı; options menüsü widget'ları sabit konumda; mouse sensitivity ayarı options panelinde kalmalı
**Actual Result**:
- Görüntü pikselleşiyor (çözünürlük düşüyor / render scale bozuluyor)
- Options menüsündeki widget'lar konumlarından kayıyor
- Mouse sensitivity slider'ı options arka planından taşıyor

## Technical Context
- **Likely affected files**: `Content/Kutun/UI/Widgets/WBP_MainMenu.uasset`, options widget (`WBP_Options` veya benzeri), `Config/DefaultGameUserSettings.ini`
- **Related systems**: UMG Canvas anchor sistemi, GameUserSettings render scale, viewport resize eventi
- **Possible root cause**:
  1. `GameUserSettings.SetScreenResolution` / `SetFullscreenMode` sonrası `ApplySettings()` çağrılmıyor veya render scale sıfırlanıyor
  2. Options widget anchor'ları piksel-bazlı (BUG-0001 düzeltmesi options widget'ı kapsamadı)
  3. Mouse sensitivity widget'ının anchor'u yanlış — viewport resize'da kayıyor
