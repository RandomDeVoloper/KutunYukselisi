## Reproduction Steps
**Preconditions**: Stand_Arena açık, hiç grab yapılmamış

1. Etkileşimli bir objeye bak (beyaz el HUD görünür)
2. Objeyi tut (grab yap)

**Expected Result**:
- Grab yapınca beyaz el HUD kaybolmalı, tek başına yeşil el HUD görünmeli
- Etkileşimli objeye yaklaşınca trace rengi beyazdan yeşile dönmeli

**Actual Result**:
- Beyaz el HUD kalmaya devam ediyor, yeşil el onun üzerine geliyor (çift HUD)
- Etkileşimli objeye yaklaşınca trace rengi değişmiyor (beyaz kalıyor)

## Technical Context
- **Likely affected files**: `Content/Kutun/Characters/Player/BP_Telekinezi.uasset`
- **Related systems**: WBP_Ref_Aim (beyaz el), WBP_HudGrab / WBP_Ref_Grab (yeşil el), trace color logic
- **Possible root cause**:
  1. IsValid guard'lar eklendi (BUG-0004 fix) ama WBP_Ref_Aim ilk grab'de hâlâ null olmayabilir — yani guard atlıyor, RemoveFromParent çağrılıyor ama widget gerçekten kaldırılmıyor
  2. Trace rengi `bIsGrabbing` değişkenine bakıyor olabilir ama bu değişken grab başlamadan önce set edilmiyor
  3. BeginPlay'de WBP_Ref_Aim oluşturulup AddToViewport yapılıyor; ilk grab'e gelene kadar Remove edilmiyor
